# CBC Senior School Results Analytics System

A Django-based web application designed to track, manage, and analyze student academic performance records, streams, and examination data tailored specifically for CBC (Competency Based Curriculum) Senior School frameworks.

## 🚀 Features

- **Academic Records Management:** Seamlessly track and update student examination data.
- **Stream & Class Segmentation:** Organize data dynamically by streams and specific class tiers.
- **Performance Analytics:** Backend-driven aggregation to help educators quickly visualize and evaluate student performance trends.
- **Environment Security:** Built-in security structures leveraging `django-environ` to keep secret keys and environment flags safe.

## 🛠️ Built With

- **Backend:** Python & Django
- **Database:** PostgreSQL / SQLite (for local development)
- **Configuration:** Django-Environ
